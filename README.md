# Clover-Cog · 四季农场

一款用 C++17、Qt 6 Widgets 和 qmake 开发的像素农场小游戏。在 72×40 的地图上种地，拿着收获去集市出售，再到商店买下一批种子和肥料。家、小路、桥和农田从开局就能探索。

## 从第一批种子开始

在首页点击「开始种田」或「继续农场」。首页和暂停页都能打开「玩法说明」，查看实际地块的样子和操作方法。

开局有 6 颗小麦种子和 3 颗土豆种子。现成的土田可以直接播种。想增加一格田，在底部工具栏选锄头，左键点可耕草地，再换种子和水壶。石路用来通行。小麦有 3 个浇过水的生长日就能收获。把 6 份小麦带到收购点，确认出售可得 **30 金币**。商店里 2 金币能买一颗胡萝卜种子，1 金币能买一份基础肥料。给未成熟作物施肥后，下一个浇过水的生长日会额外长一天，每株可施一次。

小麦四季皆可播种，土豆适合春夏，胡萝卜适合春秋，甜菜适合秋冬。已经播下的作物可以跨季生长。农产品背包可装 12 份，种子和肥料另计。

耕地、播种、浇水、施肥和收获只对角色周围八格及脚下格生效（横、纵距离均不超过1格）。点到两格外会提示距离太远，不消耗物品、不改变田地；请先走近。商店、收购、储物和睡眠仍需走到对应标记区按 F。

每季 7 天。夏天傍晚亮得久，冬天下午就开始变暗。午夜自动跨日。06:00至次日02:00前可到家中床边按F，确认休息到下一次06:00；确认期间暂停时间，取消不跳时。00:00—01:59休息到当天06:00，不多跳一天。02:00仍未休息会自动昏迷，关闭业务面板并回到床区安全位置；没有扣钱或丢物惩罚。睡眠和换季共用约0.9秒的渐黑过渡，季末休息只播放一次。

睡醒并保存成功后会响一声短音。如果进度写入失败，游戏会停在已经结算的早晨。选「重试保存」会重写这份进度，选「继续游戏」即可带着当前的农场状态继续玩。

## 操作

| 操作 | 输入 |
| --- | --- |
| 移动 | W / A / S / D |
| 选择农具、种子或肥料 | 滚轮、触控板滚动，或点击底部工具格 |
| 切换空手 | 在农场按 0，或再次点击当前物品栏格 |
| 锄地、播种、施肥、浇水 | 选中相应物品，左键点击地块 |
| 收获 | 选空手，左键点击成熟作物 |
| 打开背包、选用物品 | E 或 Tab 打开，点击农具、种子或肥料即可装备 |
| 睡眠、商店、收购 | 走到床铺或对应摊位按F；睡眠需确认，Esc取消 |
| 储物 | 站在广场箱子的正下方按 F，可存取随身农产品、种子和肥料，每次选 1 份或全部 |
| 暂停、继续、保存回首页 | 在农场按 Fsc，暂停页内可查看玩法或选择下一步 |
| 关闭面板 | Esc，背包也可用 E 或 Tab 关闭 |

在收购摊按 F，在作物旁输入要卖的份数（最少 1 份），看清这笔收入后点「卖出」。例如 6 份小麦选卖 4 份，收入 20 金币，背包还剩 2 份。「出售全部农产品」会卖光背包里的收成。种子、肥料和箱内物品都会保留。从箱子取回农产品时仍受背包容量限制。暂停页会停住游戏时间，背包、交易和储物面板打开时照常走时。

游戏在系统的应用数据目录中自动保存为 `farm-v4.json`，旁边的 `.bak` 用于恢复。有效的 v3 或 v2 农场可接续到新档，初次接续时箱子为空。旧文件保留在原位置。

## 打开、构建与运行

在 Qt Creator 打开 `CHECK.pro`，选择 Qt 6 Desktop Kit 和仓库外的构建目录，构建后运行。Mac 集成版使用 Qt 6.10.3、C++17 编译器、Widgets、Multimedia，测试另用 Qt Test。Windows 队友可以继续用原 Qt 6 Kit。Qt Creator 的 Kit、个人项目设置和构建缓存保存在本机。

在已配置好 qmake 和编译器的终端，从仓库根目录运行九组自动化测试。每组各用一个独立构建目录。

```sh
# macOS
python3 tests/run_all.py ../build-farm-tests
```

```powershell
# Windows 的 Qt / MinGW 命令行
py -3 tests/run_all.py ../build-farm-tests
```

若 Apple Clang 21 搭配 Qt 6.10.3 提示缺少 ARM intrinsic 声明，在本机 Kit 的 qmake 参数加上 `QMAKE_CXXFLAGS+=-include arm_acle.h`。测试命令可追加 `--qmake-arg 'QMAKE_CXXFLAGS+=-include arm_acle.h'`。
