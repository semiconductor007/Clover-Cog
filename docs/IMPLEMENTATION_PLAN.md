# 传统农场执行计划

本计划取代旧的“增量自动化”任务表。目标是先把日制种植做成稳定、容易理解的小型游戏，再决定是否加入更复杂的生活模拟内容。

## 阶段与分工

| 阶段 | 主要交付 | 负责域 |
| --- | --- | --- |
| S1 基础闭环 | 两种作物、日结算、背包、出售、种子商店、存档 | A 核心；B 农田；C UI/地图；D 经济；E 测试协作 |
| S2 体验清晰化 | HUD、引导、中文字体、独立贴图、错误提示 | C 主责，A/B/D 提供状态与规则，E 回归 |
| S3 内容扩展 | 新作物、扩地、分类出售、基础农具升级 | B 内容，D 经济，C 表现，A 存档兼容 |
| S4 发布打磨 | 数值试玩、音效、窗口适配、部署包 | 全员按文件责任域完成 |

## 不在当前计划

自动播种、自动收割、运输、离线收益、订单物流、NPC 社交、四季天气和复杂加工系统不进入 S1–S4。新增范围必须先更新本计划和验收场景。

## 阶段门

- **S1 门**：能完成“种下两种作物—浇水—睡眠—收获—出售—买种子”，并能重启恢复。
- **S2 门**：第一次游玩无需查看源码即可完成上述循环，关键汉字和数字清晰可读。
- **S3 门**：新内容通过配置扩展，已有存档仍可读取，扩地和出售没有重复结算。
- **S4 门**：Release 发布包在没有 Qt 开发环境的机器上启动，核心测试和人工流程均通过。
