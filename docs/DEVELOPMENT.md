### 昼夜、睡眠与家的目标规则

以下为本轮待实现的规则。当前代码仍将时钟限制在当天 23:59，跨日结算主要由睡眠触发，需要 D/B 调整后验收。

- 游戏运行期间白天和夜晚持续计时，23:59 后自然进入次日 00:00，玩家可以继续活动。
- 午夜按刚结束那一天的浇水情况进行日结算，成长与每日浇水重置各执行一次。D 负责统一结算调度，B 负责农田规则；积累多个日期时按顺序处理，重复回调或读档不能重复结算。
- 沿用 06:00 为早晨，睡眠允许时段按 20:00–次日 06:00 规划。在 20:00–23:59 睡觉跳到次日 06:00，在 00:00–05:59 睡觉跳到当天 06:00。睡眠只处理实际跨过的日期，凌晨睡觉不会额外增加一天作物成长。
- E 规划白天、黄昏、夜晚的渐变亮度/色调，C 接入场景绘制，读取同一 GameClock 时间；HUD 保持清晰。具体黄昏起止时间与夜色强度由试玩确定。
- 家的首版按同一地图上可进入的小屋区域规划，包含门口、室内活动位置及床铺。A 负责布局/房屋素材，C 负责通行，D 负责在床边按 E 睡眠，E 负责家的标识与提示。首版场景方案为规划默认值。
- 新局出生点安排在家附近。新档重开要恢复时间、玩家位置及已结算日期，睡眠、自然而来的清晨均能继续农活。

## 3. 状态与规则

- `GameClock` 昼夜持续推进时间，午夜自然跨日，日结算每个日期执行一次。
- 在家中床边睡眠跳到最近的 06:00，允许时段为 20:00 至次日 06:00，白天拒绝睡眠。
- 作物按已结束日期的浇水状态结算，自然跨日和睡眠跳时共用处理入口。
- 每块土地记录耕地、当日浇水、作物类型和有效生长日。
- 只有空耕地能播种；播种成功才扣除一颗种子。
- 只有成熟作物能收获；整格产量无法装入背包时整格失败。
- 出售只处理玩家背包，且必须通过收购点距离校验。
- 商店购买先校验金币，失败不扣金币、不增加种子。
- 存档保存完整游戏状态及已结算日期，并在原子写入失败时保留旧档。

## 4. 模块职责

| 模块 | 责任 |
| --- | --- |
| `WorldState` / `GameClock` | 土地、作物、浇水和日期结算 |
| `CropCatalog` | 作物静态配置 |
| `Inventory` / `EconomyService` | 背包容量、种子、金币、出售和购买 |
| `SaveManager` | 版本化 JSON 存档和备份 |
| `MapWidget` / `MapRenderer` | 输入、镜头和状态绘制 |
| `MainWindow` / `SeedShopDialog` | 组装界面、提示和商店交互 |

界面不得保存第二份金币、种子或作物数量，也不得在绘制或动画回调中发放收益。

## 5. 任务登记入口

本轮人员分工、具体工作、当前缺口和后续待办统一登记在第 0 节，使用 MAP-001～MAP-005 任务包。旧文档中的 FARM 编号曾存在同号不同任务的情况，认领新任务时使用本表名称和对应 MAP 编号，避免据旧编号判断任务已经分配或完成。
