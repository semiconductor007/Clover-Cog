# 地块操作距离（2026-11-14）

本地分支 `lxk-sleep-integration`，基线仍为 `09dfe88` 上的睡眠与背包未提交整合。用户授权将耕种、收获等周围交互限制在角色相邻八格内。本轮支援 C（MAP-003）的角色/地图输入、相关整窗测试与说明；无并行文件编辑者，不提交推送，原 lxk 工作区不变。接口仍需由相关主责在团队合并时审查。

## 范围

以角色当前格坐标为中心，目标的横纵差都必须小于等于1。允许八个方向及脚下；两格外、无效格或没有有效角色位置源均拒绝。每次点击实时读取角色格坐标，使用地图换算后的目标格，不以屏幕像素或固定出生位置判定。

限制耕地、播种、浇水、施肥、成熟收获，包括“持有其他农具时点击成熟作物直接收获”的分支。远程请求在物品回调前失败，不扣种子/肥料、不入包、不修改田地、不播放成功动画；界面提示靠近。直接调用角色工具入口同样检查距离。

商店、收购、储物和床铺保留走到既定标记区按 F 的本地交互，不扩大标记区。E/Tab 背包不受距离限制。此次没有新增远程交易、斧头、蓄力工具或多格灌溉。

底层 WorldState 与 MapWidget 农田服务仍允许规则计算和测试准备，不要求存在角色。玩家操作由鼠标入口与 PlayerController 约束，不把角色位置注入农田生长或存档逻辑。

## 星露谷参考

实际查阅本机反编译仓库提交 `5225ef409e42a6159a82cf81200bf6eb315c9961`：

- `StardewValley/Utility.cs`，`tileWithinRadiusOfPlayer()` 和 `withinRadiusOfPlayer()`：目标与玩家的 X、Y 坐标差分别取绝对值，并与半径比较；半径1包含斜角和脚下。
- `StardewValley/Game1.cs` 的 `tryToCheckAt()` 相关交互调用链：先通过 `tileWithinRadiusOfPlayer(..., 1, player)` 判断，再执行 `checkAction()`。

本项目用 C++/Qt 重新实现同样的格坐标判定，应用于现有的收获与工具入口。没有搬入原作工具升级、多格操作或资源。
