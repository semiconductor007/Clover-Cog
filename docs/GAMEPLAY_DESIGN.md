# Clover-Cog 传统农场玩法设计

版本：v1.0（2026-10-28）

## 核心体验

玩家每天亲自照料农田，观察作物逐日成长，再把收成带到固定收购点换成金币。玩法重点是安排一天的农活、选择种什么以及控制种子和背包的周转。

```text
买种子 → 锄地播种 → 浇水 → 睡眠跨天 → 收获 → 到站出售
```

## 第一版规则

- 播种会消耗一颗对应种子。
- 作物只有在当天浇水后才增加一天有效生长；漏浇不会死亡。
- 小麦为短周期、低产量作物；土豆为长周期、高产量作物。
- 成熟作物一次性收获，产量放不进背包时整格保留。
- 玩家必须进入收购区并按 `E` 才能出售背包内农产品。
- 金币可在种子商店购买下一批种子。
- 白天时间持续流逝；20:00 前不能睡觉。
- 作物只在夜间成功睡觉后成长一天，日期也只在此时增加。
- 时间到达夜间末尾后停留在当晚，不睡觉不会自动进入下一天。

## 玩家决策

1. 选短周期作物快速回款，还是选长周期高产作物减少播种次数。
2. 何时离开农田去出售，避免背包满导致无法收获。
3. 先购买更多种子，还是等待后续的背包、土地和农具便利升级。

## 内容节奏

### S1：学会循环

用两种作物和少量耕地，让玩家完成第一次播种、浇水、睡眠、收获和出售。

### S2：看懂状态

通过中文 HUD、成长阶段图像、操作提示和错误消息，让玩家始终知道今天该做什么、为什么操作失败。

### S3：扩大农场

加入少量新作物、可购买地块、分类出售和基础农具便利升级。所有新内容继续使用同一套日结算、库存和交易规则。

## 暂不加入

四季天气、NPC 社交、任务节日、战斗采矿、畜牧加工、自动播种、自动收割、运输和离线收益不属于首版玩法。基础循环完成试玩后，再单独评估是否加入。

## 反馈要求

- 锄地、浇水、播种和收获要有即时图像或文字反馈。
- HUD 显示日期、时间、金币、背包容量、种子和农产品数量。
- 睡醒后告诉玩家哪些作物成长、哪些因漏浇停滞。
- 白天靠近床铺时提示“晚上 20:00 后才能睡觉”。
- 背包不足、土地无效、距离收购点太远和金币不足都要说明原因。
