# Clover-Cog 传统农场玩法设计

2026-11-02 本轮目标包含自然昼夜循环、睡眠跳时和家。以下时间规则为待实现要求，当前源码仍采用睡眠推进日期，状态以 [DEVELOPMENT.md](DEVELOPMENT.md) 第 0 节为准。

版本：v1.0（2026-10-28）

## 核心体验

玩家每天亲自照料农田，观察作物逐日成长，再把收成带到固定收购点换成金币。玩法重点是安排一天的农活、选择种什么以及控制种子和背包的周转。

```text
买种子 → 锄地播种 → 浇水 → 自然跨日或回家睡眠 → 收获 → 到站出售
```

## 第一版规则

- 播种会消耗一颗对应种子。
- 作物只有在当天浇水后才增加一天有效生长；漏浇不会死亡。
- 小麦为短周期、低产量作物；土豆为长周期、高产量作物。
- 成熟作物一次性收获，产量放不进背包时整格保留。
- 玩家必须进入收购区并按 `E` 才能出售背包内农产品。
- 金币可在种子商店购买下一批种子。
- 时间昼夜连续流逝，午夜自然进入下一天，按刚结束日期的浇水状态结算作物。
- 家有可进入的小屋区域和床铺，夜间在床边按 E 跳过剩余夜晚。
- 睡眠目标为最近的 06:00，允许时段为 20:00–次日 06:00，自然跨日与睡眠跨日每个日期只结算一次。
- 白天、黄昏和夜晚呈现渐变亮度与色调，夜晚保留道路及交互点可读性。

## 玩家决策

1. 选短周期作物快速回款，还是选长周期高产作物减少播种次数。
2. 何时离开农田去出售，避免背包满导致无法收获。
3. 先购买更多种子，还是购买基础肥料改善作物成长。

## 内容节奏

### S1：学会循环

用两种作物和少量耕地，让玩家完成第一次播种、浇水、睡眠、收获和出售。

### S2：看懂状态

通过中文 HUD、成长阶段图像、操作结果和错误消息，让玩家始终知道今天该做什么、为什么操作失败。

### S3：扩大农场

加入少量新作物，并一次性扩大现有地图，新区开局可进入。本轮加入商店购买基础肥料及一个固定施肥效果，由 D/B 配合完成。分类出售和购买自选数量保留为后续待办。所有新内容继续使用同一套日结算、库存和交易规则。

## 暂不加入

四季天气、NPC 社交、任务节日、战斗采矿、畜牧加工、自动播种、自动收割、运输和离线收益不属于首版玩法。基础循环完成试玩后，再单独评估是否加入。

## 反馈要求

- 锄地、浇水、播种和收获要有即时图像或文字反馈。
- HUD 显示日期、时间、金币、背包容量、种子和农产品数量。
- 每次日结算后告诉玩家哪些作物成长、哪些因漏浇停滞，睡醒后的提示读取同一结算结果。
- 家和门口有清楚标识，白天在床边提示夜间可睡，夜间提示“按 E 睡到早晨”。
- 背包不足、土地无效、距离收购点太远和金币不足都要说明原因。
