# 背包格位与拖动（2026-11-14）

本轮由用户明确授权完成背包拖动、拆分、合并、物品栏和箱子联动。C/D/E 顺序整合窗口包括 EconomyService、InventoryDialog、ItemBar、StorageDialog、MainWindow、SaveManager、共享 SlotGrid 及相关构建/测试。没有并行文件编辑者，按用户授权提交推送到 `lxk`；保留前几轮尚未提交的界面调整。旧文档中的“尚未实现拖拽”是历史状态，以本文件为准。

## 操作

- 左键拖动物品到空格移动；同类目标合并；异类目标交换整组。部分数量不能与异类交换，失败保留原位。
- 右键拖动一份；Shift+右键拖动向上取整的一半。右键短点也可拆一份到首个空格，Shift+右键短点拆一半。工具不能拆分。
- 背包第一排就是七格物品栏。移动到首排会更新场景物品栏，点击首排选用；下方物品可以拖到首排，也可拖到场景底部真实物品栏。场景物品栏自身也可左键拖动换位。
- 箱子窗口上方是箱内格子，下方是随身背包，可双向拖动；箱子可滚动，不能把物品放进被滚动区域裁掉的不可见格。
- 松开到无效位置、Esc取消拖动、关闭窗口、暂停或昏迷打断，不会丢物品。只有通过服务验证的落点一次性改变状态，不把物品提前从库存取到临时鼠标仓库。
- 保留 E/Tab/Esc 关闭背包、F站点操作、0切换空手及现有保存失败处理。没有增加整理、丢弃、装备或升级。

## 星露谷参考与项目差异

本项目保留七列三排共21个随身格，箱子首批42格，填满后扩展七格（元数据安全上限65536格）；保留农产品12份总容量、种子和肥料另计。未引入原作的999堆叠上限或购买扩容数值，非工具堆叠沿用现有 int 数量范围，工具固定一份。格子满时新增不同物品或拆分失败，不扣钱/物品；同类仍可继续合并。

界面只提交意图与显示快照。服务维护格位分配与已有数量模型的一致性，拖动不会增加/减少总数；交易和农田消费通过同一经济服务更新格位，种植/施肥优先扣当前选中格，整格收获仍先检查容量。收获物可放在物品栏，角色按空手处理，不伪装成农具。

`StackMove` 携带来源侧、来源格、目标侧、目标格、数量、来源堆叠快照与库存 revision。越界、过期、重放、数量不足、部分交换、容量或整数溢出均在候选状态失败，不改变真实库存。主窗口另外校验当前面板、时钟/睡眠状态及箱子站点，UI不能绕过。QGraphicsProxyWidget 内的真实物品栏使用场景坐标变换定位，支持缩放窗口。
