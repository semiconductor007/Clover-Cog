# 背包查看面板验收记录

日期：2026-10-25。基线：stage1 / ff21ee8；本轮未提交修改。

范围：C 的背包显示、角色输入与窗口缩放；A 的 qmake 注册配合。使用现有 EconomyService::state() 只读值快照；没有新增库存资产或改动公共经济契约。

## 当前功能

- B 打开/关闭，Esc 与 CLOSE 关闭。
- 显示金币、已用/总容量、两种作物及种子数量、售价/种价和成长天数。
- 使用 Inventory_Spritesheet.png 的槽位素材；W/P/S 是临时文字标识，尚未映射最终物品图标。
- 面板覆盖整个逻辑画布并随窗口缩放；停止移动、禁用地图输入，关闭恢复焦点。时间继续。
- 根据视口实际 Resize 事件更新缩放，修复初次启动时布局未完成导致画面过小。

## 实际 GUI 检查

Qt 6.8.2 / MinGW 64-bit Release，Windows 桌面；通过 computer-use 直接观察应用并操作。

| 操作 | 结果 |
| --- | --- |
| 启动普通窗口 | 地图、角色、HUD 和工具栏显示正常，画面占满逻辑视口 |
| B 打开 | 面板显示 BAG 0/12、COINS 0、作物数量0、种子数量与 HUD 一致 |
| 面板内按 D，再关闭 | 人物位置保持不变 |
| B 关闭 | 地图重新可见，人物显示正常 |
| 最大化并 B 打开 | 面板随画布缩放，四行数据及底部按钮完整可见 |
| Esc 关闭 | 最终版本已实际复测成功 |
| 鼠标点击 CLOSE | 关闭成功，恢复地图画面 |

尚未验收：非零作物数量与满背包的实际 GUI 场景、多显示器 DPI 切换、其他分辨率、中文字体、最终作物图标。背包数量/容量交易仍复用原有核心逻辑测试。
