## 星露谷参考

参考仓库 Dannode36/StardewValleyDecompiled，实际提交 5225ef4。

- Stardew Valley/StardewValley/GameLocation.cs：startSleep、doSleep。床交互进入统一新日流程，保存最后睡眠位置等状态。
- Stardew Valley/StardewValley/Game1.cs：performTenMinuteClockUpdate、newDayAfterFade、_newDayAfterFade。时间推进和新日处理集中实现，新日设置06:00。
- Stardew Valley/StardewValley/Utility.cs：CalculateMinutesUntilMorning。将睡眠时刻换算为到早晨的时间差，明确使用26小时制。

采用的结构：目标时间计算与世界结算分开；睡眠只改变统一时钟，由现有统一日切入口决定农田成长；没有在床交互中另写成长算法。

项目差异：原作以延续至26:00的游戏日处理新日。本项目明确午夜切换日期，夜间20:00至06:00可睡，凌晨睡到当天06:00。因此不复制原作新日必增日的行为，也不直接搬运C#代码或联机同步流程。

## 规则

| 时刻 | 行为 |
| --- | --- |
| 00:00—05:59 | 当天06:00，不增加日期 |
| 06:00—19:59 | 拒绝睡眠，时钟不跳转 |
| 20:00—23:59 | 次日06:00，经过一次午夜 |

成功睡醒后再次请求会因处于06:00被拒绝。自然经过的时间仍会正常流逝，“失败不变”指不额外跳时。睡眠时刻设置会重启单调计时基点，保留目标整分钟语义。
