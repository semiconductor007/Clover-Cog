# UI 与玩法素材盘点

盘点日期：2026-10-22。基于仓库文件、实际图像、character.qrc 和字体字形表核对。仅为素材与接入方案分析，未改动游戏界面。

## 1. 结论

第一版的背包、金币显示、售卖面板、强化商店和基础收购点，可以主要使用现有素材制作。自动化设备、背包等级外观和角色背负表现需要补充或改绘。

仓库有 280 个 PNG 文件，按文件内容去重为 222 份；有些目录是重复素材或同图的副本。character.qrc 中包含 48 个不同 PNG 文件路径，大量现成 UI 和物品图标尚未接入资源系统。这些数字表示文件数量，不表示独立游戏道具数量。

当前视觉以 Sprout Lands 的低饱和草绿、浅木色、米色面板、棕色边框和小尺寸像素图标为主。项目还带有 Farm RPG FREE 16x16 素材，其部分家具颜色明显更鲜艳；新增主界面优先沿用 Sprout Lands 图集。

## 4. 第一版界面制作建议

### 背包

用现有面板边角与槽位组合出窗口，同类农产品堆叠显示，附数量。顶部单独显示“携带 9/12”，与总容量规则对应；槽位数量不直接等于容量。已有素材中的爱心是装饰组件，当前玩法不需要体力/生命条，可省略。

### 收购站与出售

地图里用 Sprout Lands 木屋部件、工作台、箱子和带图标的招牌拼出固定收购点。靠近显示交互提示，进入交易后用现有浅色面板显示背包物品与价格。第一版可以是自助收购站，独立商人 NPC 外观在需要时再制作。

### 强化与售卖入口

使用同一套按钮边框和图标。工具升级用现有工具图标，种子升级用对应种子袋；背包升级先用容量数字、等级标记和临时篮子图标表达。功能逻辑仍需编写，没有现成可直接运行的商店界面。

### 像素缩放与文字

保持像素素材整数倍率和最近邻缩放，面板采用九宫格或分块拼接，避免整张窗口拉伸。世界图块以当前 16×16 为基准，角色使用其原有较大帧尺寸；新增设施要同时定义占地格数、锚点和碰撞范围。

已检查 pixelFont-7-8x14-sproutLands.ttf 的字符映射：基础汉字区 U+4E00–U+9FFF 字形数为 0，已有数字与拉丁字母。中文“背包、出售、金币”等标签需使用支持中文的配套字体；数字可继续用当前像素字体。中文字体尚未选定。

## 5. 新素材制作优先级

1. 第一版先用现有素材完成背包、到站售卖和强化界面；确认各作物图标与生长阶段。
2. 需要区别时补 3–4 档背包图标，以及箱子的收购/存储标记。
3. 自动化阶段补喷灌器、稻草人和运输小车，先覆盖待机、工作、满载/停工的可读状态。
4. 最后补角色背负、搬运和卸货细节，作为表现提升，不作为背包逻辑的前置依赖。

以上“未发现”指本次仓库文件与相关图集检查结果，不代表素材作者其他版本中没有这些资源。
