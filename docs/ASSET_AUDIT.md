# 传统农场 UI 与素材盘点

盘点日期：2026-10-28。本文只记录当前传统农场版本需要的素材，不规划自动化设施、运输工具或增量生产装置。

## 当前可复用素材

| 用途 | 现有素材 | 处理方式 |
| --- | --- | --- |
| 地图与角色 | Sprout Lands 地图、角色精灵、工具动作 | 保留现有像素风格和 16×16 地图基准 |
| 工具栏 | `itembar/` 槽位图和工具图标 | 继续显示空手、斧头、锄头、水壶和种子 |
| 背包 | Inventory 图集、槽位和木框面板 | 组合出容量、种子和农产品数量显示 |
| 收购点 | 工作台、箱子、招牌和木屋部件 | 组成固定收购区，并显示 `SELL [E]` |
| 种子商店 | 米色面板、按钮、货币和种子袋图标 | 显示价格、持有数量和购买按钮 |
| 作物 | `Farming Plants` 生长图、种子/收获物图标 | 接入小麦、土豆及后续作物阶段 |
| 睡眠点 | 地图中的床铺和交互标记 | 显示白天不可睡、夜间可睡的提示 |

## 仍需补充

- 小麦和土豆清晰可区分的播种、成长、成熟图像。
- 支持中文的像素字体；当前字体主要覆盖数字和拉丁字母。
- HUD、背包、出售和种子商店中的中文文本布局。
- 基础肥料的物品图标和施肥状态显示；E 按 B 确认的品种清单准备作物图像。

## UI 原则

- 继续使用浅木色、米色面板、棕色边框和低饱和草绿色。
- 像素素材采用整数倍率和最近邻缩放。
- HUD 至少显示日期、时间、金币、背包容量、种子和农产品数量。
- 白天靠近床铺显示夜间可睡眠，允许时段为 20:00–次日 06:00；跨日与睡眠提示读取统一结算结果。
- 背包不足、无种子、金币不足、距离收购点太远等情况必须有明确提示。
