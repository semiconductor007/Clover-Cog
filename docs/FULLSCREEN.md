## 行为

全屏尺寸变化时同步画布、嵌入视口的画布代理及地图范围，避免右侧地图和状态面板按旧宽度被裁切。
窗口回归从全屏首页进入农场，在 2560×1600 视口验证右边缘的地图和状态面板像素。

- main() 使用 `showFullScreen()`；窗口已有无系统边框标志，不显示 Windows 标题栏。
- F11 切换全屏/普通无边框窗口，切换后重新计算视图布局。
- 全屏按屏幕宽高比扩展地图的逻辑宽度，逻辑高度仍为442，使用同一比例缩放横纵轴。
  地图显示更多横向区域，不将人物拉宽、不沿用普通窗口的整数倍率留边。
  屏幕像素取整可能产生至多约1像素边差；宽高比不同不会产生原4:3画布的大幅侧边留白。
- 地图铺满画布。右上角的日期、时钟、单行金币框和独立水量框随窗口宽度重新定位，底部七格物品栏居中。操作提示在左侧可用空间内换行，显示期间仍可点击下方地块。
- 返回窗口模式恢复576×442逻辑画布和原有缩放规则；Esc使用主线暂停菜单，Alt+F4沿用保存退出。
