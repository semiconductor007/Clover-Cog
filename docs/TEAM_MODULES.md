## 协作边界

- A 单人保存地图、QRC 和构建清单，其他成员提交资源清单或坐标建议。
- B 从 E 的累计日期推导季节，不维护第二套时钟；E 调用 B 的农田结算，每个日期只处理一次。
- B 负责施肥效果，D 负责购买/库存/成功扣除，C 负责选择/施用输入；失败不消耗。
- D 背包只显示现有库存；选择意图交 C 同步工具栏，不建立 UI 库存副本。
- 主窗口按 D 背包/交易/保存→E 时间/睡眠/HUD 交接，C 提供地图挂接点；共享测试依次编辑。
- 各自独立分支、自测并更新文档，全组验证新局、换季/跨年、午夜/睡眠、满包及存档重开。Mac/Windows 分别记录实际结果。
