# 团队模块职责

本轮进行一次性地图扩建，并在小麦、土豆基础上新增 1–2 种作物，并加入自然昼夜循环和可回家的小屋，按下表分配到五人。新增区域开局即可进入。成员姓名和 GitHub 账号待登记，具体任务、状态和完成条件以 [DEVELOPMENT.md 第 0 节](DEVELOPMENT.md#0-本轮任务分配2026-11-02) 为准。

| 成员 | 负责内容 | 本轮交付 |
| --- | --- | --- |
| A 地图制图 | Tiled 布局、地形、河流、道路、木桥、小屋、屋内床铺布局和地图资源 | MAP-001，扩大后的地图与家，资源登记及最终发布包汇总 |
| B 品种确认、农田与作物 | 独立确认新增品种，新田、成长天数、产量和阶段图块，施肥效果，和 D 对齐价格 | MAP-002，3–4 种作物完整循环、全部作物阶段映射，配合数值试玩 |
| C 通行与种植输入/显示 | 移动、碰撞、镜头、新种子选择与播种、成长显示、家门通行、昼夜绘制接入及施肥输入 | MAP-003，新区可探索，新作物可操作与显示 |
| D 时间/睡眠与作物交易 | 自然跨日调度、家中睡眠、功能区、全部作物交易及基础肥料的购买/库存/扣除，和 B 对齐施肥及日结算 | MAP-004，自然时间与睡眠、全部作物交易、新档及异常恢复；简单道具先实现基础肥料，交易待办由 D 牵头 |

## 约束

- UI 不持有可写的金币、种子、背包或农田副本。
- 农田不直接修改金币，经济服务不直接改变作物成长。
- D 依据统一 GameClock 调度自然跨日与睡眠跳时，B 维护农田结算，同一日期只处理一次。
- 自动化、运输和离线收益暂不分配开发文件；若未来立项，再新增责任说明。
- 修改公共头、`CHECK.pro`、资源清单或存档格式前，必须让文件主责与直接消费者审阅。
- 每人自测对应功能，全组共同试玩，E 同时负责界面开发。

## 协作顺序

先在本页成员认领表登记角色与实际成员，再按 MAP 编号创建各自分支。A 统一编辑地图文件，B/C 提供图层需求；B 独立确认品种并交付规则及目录，E 按清单准备素材，C/D/E 接入种植、交易与显示；D/B 先确定时间与结算契约供 C/E 消费，D 完成主窗口时间、睡眠、功能区和交易接入后将文件交给 E，C 的主窗口缩放需求由 E 接入。交接后再编辑共享文件。提交前运行应用和相关核心测试，并记录实际平台及尚未执行的 GUI 检查。
