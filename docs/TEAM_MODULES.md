# 团队模块职责

项目采用五个责任域。成员姓名和 GitHub 账号待登记；本表用于避免多人同时改同一份业务状态。

| 域 | 负责内容 | 近期交付 |
| --- | --- | --- |
| A 核心与存档 | `GameClock`、状态组装、存档版本和集成 | 日结算唯一入口、存档兼容、构建基线 |
| B 农田与作物 | `WorldState`、`CropCatalog`、耕地/播种/浇水/成长/收获 | 两种作物表现、新作物配置、扩地规则 |
| C 角色/地图/UI | 移动、地图呈现、HUD、工具栏、提示和商店窗口 | 中文 HUD、新手引导、独立成长贴图 |
| D 经济与库存 | `Inventory`、`EconomyService`、金币、出售、种子购买 | 分类出售、购买数量、基础便利升级 |
| E 测试与内容支持 | 规则回归、资源登记、试玩记录和发布检查 | S2 边界测试、素材许可、发行包验收 |

## 约束

- UI 不持有可写的金币、种子、背包或农田副本。
- 农田不直接修改金币，经济服务不直接改变作物成长。
- 日结算只由 `GameClock` 触发一次。
- 自动化、运输和离线收益暂不分配开发文件；若未来立项，再新增责任说明。
- 修改公共头、`CHECK.pro`、资源清单或存档格式前，必须让 A 与直接消费者审阅。

## 协作顺序

先在 [DEVELOPMENT.md](DEVELOPMENT.md) 确认任务和验收，再修改所属文件；跨域改动记录依赖和测试。提交前运行应用和核心测试，并在文档中说明未执行的 GUI 检查。
