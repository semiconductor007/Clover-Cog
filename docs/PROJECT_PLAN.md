# Clover-Cog 传统农场项目规划

版本：v1.0（2026-10-28）

## 1. 项目定位

Clover-Cog 是一个使用 C++17、Qt 6 Widgets 和现有像素素材制作的小型单机农场游戏。玩家每天亲自照料一块小农田，通过出售收成购买下一批种子，逐步扩大可管理的农场。

本版本选择传统日制农场玩法，核心体验是“安排一天的农活并观察作物逐日成长”。项目暂不以增量放置、自动生产或离线收益为主要目标。

## 2. 核心循环

```text
购买种子 → 锄地播种 → 每日浇水 → 自然跨日或回家睡眠
    ↑                                      ↓
    └──────── 收获成熟作物 → 到收购点出售 ─┘
```

- 种子是消耗品，成功播种会减少库存。
- 作物按有效浇水日成长；漏浇只会停滞，不会死亡。
- 玩家亲自收获，并把作物装入有限背包。
- 只有到达地图上的收购点才能出售，出售后获得金币。
- 金币优先用于购买种子和改善农场操作。

## 4. 设计原则

- 时间昼夜持续流逝，午夜自然跨日，玩家安排农活并可回家睡眠跳过夜晚。
- 睡眠时段按 20:00–次日 06:00 规划，跳到最近的 06:00；午夜和睡眠调用同一日结算入口，同一日期只处理一次。
- 规则以作物和土地状态为准，图块只负责呈现。
- 收获、出售、购买失败时状态保持不变，并给出原因。
- UI 只提交操作并显示状态，金币、种子、背包和农田由游戏状态统一管理。
- 所有数值集中在作物/经济配置中，先保证可玩，再通过试玩调整。

## 6. 主要验收场景

1. 新玩家能在同一天完成锄地、播种和浇水。
2. 自然跨日和睡眠跳时按浇水情况结算，日期不重复处理，漏浇不会死亡；夜间在家可选择睡眠。
3. 小麦和土豆的成熟天数、产量和售价有明显区别。
4. 背包不足时不能收获，成熟作物保留在原地。
5. 远离收购点不能出售；出售后金币和背包数量同时正确变化。
6. 重启后日期、金币、种子、背包和田地状态保持一致。
