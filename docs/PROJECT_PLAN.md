# Clover-Cog 传统农场项目规划

版本：v1.0（2026-10-28）

## 1. 项目定位

Clover-Cog 是一个使用 C++17、Qt 6 Widgets 和现有像素素材制作的小型单机农场游戏。玩家每天亲自照料一块小农田，通过出售收成购买下一批种子，逐步扩大可管理的农场。

本版本选择传统日制农场玩法，核心体验是“安排一天的农活并观察作物逐日成长”。项目暂不以增量放置、自动生产或离线收益为主要目标。

## 2. 核心循环

```text
购买种子 → 锄地播种 → 每日浇水 → 睡眠进入下一天
    ↑                                      ↓
    └──────── 收获成熟作物 → 到收购点出售 ─┘
```

- 种子是消耗品，成功播种会减少库存。
- 作物按有效浇水日成长；漏浇只会停滞，不会死亡。
- 玩家亲自收获，并把作物装入有限背包。
- 只有到达地图上的收购点才能出售，出售后获得金币。
- 金币优先用于购买种子和改善农场操作。

## 3. 内容边界

### 当前版本（已落地的基础闭环）

- 角色移动、碰撞、工具栏和像素地图。
- 小麦、土豆两种作物及不同生长周期、产量和售价。
- 锄地、播种、浇水、成熟、收获和睡眠跨天。
- 有容量的背包、固定收购点、金币和种子商店。
- 本地 JSON 存档、备份恢复和核心规则测试。

### 下一阶段

1. 新手引导和更清晰的中文 HUD。
2. 作物独立贴图、成长阶段反馈和操作提示。
3. 更多作物与简单的土地扩建，保持规则易懂。
4. 分类出售、种子购买数量和基础农具升级。

### 暂缓内容

四季天气、NPC 社交、任务节日、战斗采矿、畜牧加工、联机、自动播种/收割/运输、离线收益和复杂升级树。只有基础日制循环稳定后，才重新评估这些内容。

## 4. 设计原则

- 白天时间持续流逝，玩家需要安排当天的农活；20:00 后才能睡觉。
- 睡眠是唯一的日期推进和作物成长结算点，未睡觉不会自动进入下一天。
- 规则以作物和土地状态为准，图块只负责呈现。
- 收获、出售、购买失败时状态保持不变，并给出原因。
- UI 只提交操作并显示状态，金币、种子、背包和农田由游戏状态统一管理。
- 所有数值集中在作物/经济配置中，先保证可玩，再通过试玩调整。

## 5. 里程碑

| 阶段 | 目标 | 验收重点 |
| --- | --- | --- |
| S1 | 基础种植闭环 | 两种作物可播种、浇水、睡眠成长、收获和出售 |
| S2 | 可理解性 | 中文 HUD、引导、成长阶段贴图、错误提示和存档提示 |
| S3 | 农场扩展 | 3–4 种作物、有限扩地、分类出售和基础农具升级 |
| S4 | 内容打磨 | 数值试玩、音效、窗口适配、发布包和回归测试 |

当前代码已达到 S1 的第一版，下一次开发从 S2 开始。

## 6. 主要验收场景

1. 新玩家能在同一天完成锄地、播种和浇水。
2. 睡眠后作物只按浇水情况推进一次，漏浇不会死亡。
3. 小麦和土豆的成熟天数、产量和售价有明显区别。
4. 背包不足时不能收获，成熟作物保留在原地。
5. 远离收购点不能出售；出售后金币和背包数量同时正确变化。
6. 重启后日期、金币、种子、背包和田地状态保持一致。
