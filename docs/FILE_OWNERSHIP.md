## 修改边界

- UI 不得持有第二份金币、种子、背包或农田状态。
- B 不直接修改金币，D 不直接推进作物成长。
- 午夜自然跨日，睡眠跳到最近早晨，共用日结算入口且每个日期只结算一次。
- 新作物、扩图和肥料必须复用现有服务，不创建独立的重复库存或经济算法。
- 本版本不设置自动化、运输、物流或离线收益的文件所有权。

## 协作窗口

修改公共头、存档字段、`CHECK.pro`、测试工程或资源清单时，在提交说明中列出影响文件和验证命令。不同成员不得在同一工作目录同时编辑同一文件。

地图由 A 单人保存，B/C/D 用坐标清单、图层说明或标注图交付需求。D 的主窗口修改完成后，先交付可构建版本并记录分支或提交，再由 E 基于该版本编辑。`mapwidget.*` 和 `maprenderer.*` 中的农田显示、地点标识需求统一交 C 接入。新增作物先由 B 交付目录和规则，C 同步扩展工具类型及播种输入，E 和 C 对齐工具栏索引、种子图标与操作，D 接入商店与交易。涉及公共头的改动先由直接消费者确认。夜色绘制由 C 接入 maprenderer/mapwidget，E 提供方案并处理 HUD，统一读取 D 的 GameClock。D/B 先交付自然跨日与睡眠的结算契约，相关测试由 D/B 按顺序编辑。共享测试文件由需要修改的作者依次交接。
