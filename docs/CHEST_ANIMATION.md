# 储物箱开合与短音效

## 本次范围与文件窗口

用户授权在已有箱子功能上实现开合动画并配音效。基线 `99d0f58`，本地分支
`lxk-sleep-integration`，增量任务 `CHEST-UI-001`。由当前会话顺序支援 C 的
`src/map/mapwidget.*` / `maprenderer.*`、D/E 的 `src/app/mainwindow.*`、
A 的 `farm-sounds.qrc` 与音频资源、共享 `tests/clock_ui/clock_ui_tests.cpp`。
另新增 `tools/generate_chest_sounds.py`，更新本文、接口与素材记录和开发入口。
没有并行编辑者；正式成员账号仍待团队登记，消费者审查不以自测替代。
不修改经济服务、地图布局、库存数量、保存格式、作物或时间规则。

## 原作参考与项目映射

只读查阅第三方反编译仓库提交 `5225ef4` 中
`Stardew Valley/StardewValley.Objects/Chest.cs`：

- `checkForAction()`：箱子互动成立后启动帧计时，播放 `openChest`，停止角色动作。
- `updateWhenCurrentLocation()`：推进箱盖，最后一帧到达后才调用 `ShowMenu()`；
  菜单消失后释放访问状态并播放 `doorCreakReverse`。
- `fixLidFrame()` / `resetLidFrame()`：将箱盖恢复到关闭状态。

采用“验证入口 → 停止操作 → 开盖和开箱音 → 开完后打开菜单 → 菜单关闭后闭盖和关箱音”
的处理顺序。使用本项目 Qt 计时器、精灵和音频，不复制 C# 工程或原作音频。
本项目单机，无原作多人互斥锁；时间仍按既有规则自然流逝，02:00 仍优先昏迷。
关箱使用本项目的反向精灵帧表现，不声称原作也采用相同的反向播放。

## 绘制与时序

沿用地图箱子 `(31,20)`，站在南邻格 `(31,21)` 按 F。
现有 `sprout/Chest.png` 是 240×96 的图集，前向五帧间隔 48 像素。
第 n 帧采样矩形为 `(16 + 48*n, 0, 16, 32)`，n 为 0–4。
地图原来的闭箱 local tile id 为 16，只有指定储物点对应的这个 Chest.tsx 图块会被替换。
上方留出一格透明盖子空间，不叠画旧闭箱、不擦除地面、不改地图数据或碰撞。
绘制仍使用当前季节图集和镜头偏移，处在既有地图/角色/夜色/HUD 的层次中。

用 `QElapsedTimer` 推导帧，不依赖游戏时钟或渲染帧数。
开盖每帧约 80ms，最后一帧停留后才发出打开完成通知，完整开盖约 400ms；
菜单打开时停在末帧，关闭后反向合盖约 320ms。
关箱过程中再次互动可从当前帧反向打开，不重复创建窗口。

开盖期间阻止移动、农具、背包和站点重复互动；Esc 可以取消。
完成时重新检查页面、站点位置、过渡、睡眠/保存错误等条件。
取消、退出、跨季过渡或昏迷打断会撤销待开的菜单；旧计时通知不能再弹出储物界面。
关闭菜单后沿用原有输入与焦点恢复流程。动画及声音回调均不写库存或存档。

## 音效

`resources/audio/chest_open.wav` / `chest_close.wav` 分别为原创合成的铰链/搭扣声，
通过 `tools/generate_chest_sounds.py` 的标准库算法确定性生成。
没有第三方采样或星露谷资源。PCM16 单声道，22050Hz，开箱0.34秒、关箱0.24秒。
QRC 路径为 `:/sounds/chest_open.wav` 与 `:/sounds/chest_close.wav`，
对象名为 `chestOpenSound` / `chestCloseSound`，各由界面生命周期管理，音量0.40。
只在目标开合状态改变时各请求一次；资源未就绪、缺失、静音、音量0或无默认输出时跳过，
不会排队补播，不等待音频完成，不影响存取和动画完成。
